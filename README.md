# github-open-source-dio
Desafio prático de Git e GitHub para iniciantes (DIO)


## 📌 Sobre o desafio
Projeto criado para um desafio da **DIO (Digital Innovation One)** com foco na prática de **Git, GitHub e Pull Requests**.

---

## 🎯 Objetivo
Contribuir com o projeto escolhendo **uma das alternativas abaixo**, utilizando corretamente o fluxo de Pull Request.

---

## 🚀 Como contribuir (escolha UMA opção)

### ✅ Opção 1 — Adicionar seu perfil (recomendada)
1. Faça um fork do repositório
2. Crie uma branch
3. Adicione um arquivo `.md` em `participants/`
4. Siga o padrão do `example.md`
5. Abra um Pull Request

---

### 📝 Opção 2 — Melhorar a documentação
- Corrigir erros de português
- Melhorar explicações no README
- Ajustar o CONTRIBUTING.md

---

### ⚙️ Opção 3 — Melhorar a automação
- Ajustar o workflow de validação
- Melhorar mensagens de erro do GitHub Actions

---
