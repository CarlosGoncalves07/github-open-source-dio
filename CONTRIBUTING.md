# Minha contribuição

✅ Seção sugerida: Boas práticas e erros comuns
## Boas práticas

- Crie sempre uma branch específica para sua contribuição.  
  Evite trabalhar diretamente na branch `main`.

- Escolha **apenas uma forma de contribuição** por Pull Request.  
  Isso facilita a revisão e evita reprovações.

- Utilize mensagens de commit claras e objetivas, descrevendo o que foi feito.  
  Exemplo: `docs: melhora explicações no CONTRIBUTING`.

- Leia atentamente o `README.md` e este `CONTRIBUTING.md` antes de começar.

- Respeite o padrão definido pelo projeto, especialmente ao adicionar arquivos ou editar documentação.

- Aguarde a validação automática do GitHub Actions antes de solicitar revisão.

---

## ❌ Erros comuns (evite)

- Criar Pull Request com mais de um tipo de contribuição (ex: documentação + código).

- Alterar arquivos que não fazem parte da contribuição escolhida.

- Modificar regras do projeto ou critérios de aceitação.

- Enviar Pull Request sem preencher corretamente o template.

- Trabalhar diretamente na branch `main`.

- Ignorar falhas apontadas pelo GitHub Actions.
